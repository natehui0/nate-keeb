# nate-keeb

# Custom Mechanical Keyboard

A custom mechanical keyboard designed and built from scratch using KiCad and Onshape. This project started as a way for me to learn more about PCB design, electronics, CAD, and mechanical keyboards, while pursuing my interest in keyboards.
